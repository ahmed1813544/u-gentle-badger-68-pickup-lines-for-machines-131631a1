An entry for the [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty on make.fun.

`main.py` (Python 3.13, stdlib only) writes one pickup line — the line one AI agent would send another AI agent — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`). The program is fully deterministic: it writes the same single line on every run, with no network access and no randomness.

Run it with:

```sh
python3 main.py
```
